# 隐私说明

每日背屏无需注册项目账号，没有项目自建的素材服务器或分析统计服务。应用数据默认保存在手机上。

## API Key 与网络请求

- API Key 使用 Android Keystore 的 AES-GCM 加密保存在应用私有数据中；APK 和源码不包含使用者的密钥。
- 调用 AI 服务时，密钥通过 HTTPS 发送给你在设置中选择的服务。使用自定义服务地址前，请确认该服务可信；更换兼容服务域名需要重新输入密钥。
- 生成请求会发送选题、提示词及创作偏好；服务商可能依据其政策保存请求并收费。应用不会自动把相册或当前背屏图片上传给视觉模型。
- 在线素材请求会向来源站点暴露正常联网所需的信息（例如 IP 地址、搜索关键词）。内置网页遵循来源网站自身的隐私政策。

## 本机数据与系统权限

图片、视频、收藏、历史和设置保存在手机中。为适配系统背屏，当前视频会写入本机 MediaStore；系统主题管理器和背屏服务可读取当前展示素材。API Key 不会通过媒体接口暴露。

Shizuku 或 ADB 用于把本项目模板安装到系统主题管理器的对应目录。安装服务核对调用身份和脚本摘要，不提供任意命令执行接口。日常更换素材无需持续运行 Shizuku。

应用关闭系统自动备份。清除应用数据会删除配置、密钥密文及应用私有缓存；已导出到公共媒体库的文件和已安装的系统背屏模板可能仍需手动清理，恢复方法见[使用指南](rear-screen-setup.md)。

## 提交问题前

请遮盖 API Key、个人素材、设备序列号和私人服务地址。不要将完整配置导出或未经检查的日志贴到公开 Issue 中。
